# EduTech - פלטפורמת טכנולוגיה חינוכית

פלטפורמת טכנולוגיה חינוכית מודרנית עם Next.js 15, Supabase ו-Radix UI. כוללת ניהול קורסים, אימות משתמשים, ותמיכה בעברית.

## תכונות

- קטלוג וניהול קורסים
- אימות משתמשים דרך Supabase
- עיצוב רספונסיבי עם Tailwind CSS
- רכיבי Radix UI נגישים
- תמיכה ב-RTL עברי
- TypeScript לבטיחות טיפוסים

## טכנולוגיות

| טכנולוגיה | שימוש |
|-----------|-------|
| Next.js 15 | פריימוורק React |
| Supabase | Backend ואימות |
| Tailwind CSS | עיצוב |
| Radix UI | רכיבי UI נגישים |
| TypeScript | בטיחות טיפוסים |
